README – Hallazgos del análisis
Hallazgos
1. Producto con mayor facturación

El Producto 1 es el que genera la mayor facturación, con un total de $3.600, lo que representa aproximadamente el 55,9% de la facturación total.

2. Producto con mayor cantidad de unidades vendidas

El Producto 2 es el que registra la mayor cantidad de unidades vendidas, con 13 unidades. Sin embargo, genera una facturación de solo $364, debido a su menor precio unitario.

3. Clientes recurrentes

Los 5 clientes realizaron 2 pedidos cada uno, por lo que todos cumplen con el criterio establecido de cliente recurrente.

Conclusión

Los resultados muestran que el producto con mayor volumen de ventas no necesariamente es el que genera mayor facturación. En este caso, el Producto 1 lidera en ingresos, mientras que el Producto 2 lidera en cantidad de unidades vendidas.

Además, se observa un comportamiento de compra recurrente, ya que el 100% de los clientes analizados realizó más de un pedido.
